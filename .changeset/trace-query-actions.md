Adds the queries an agent starts a failure with. `traceSummary` gives the runner, browser or device, duration, outcome, counts of actions, failed actions, failed steps, console errors and failed requests, the first error and the test tree with each test's outcome. `traceErrors` lists failed actions, steps that failed on their own (such as a failing hook), console errors and failed requests in time order, each naming the action it happened during. `traceActions` pages the actions in the order they ran, with a wait's polls nested under it, filterable by status, test and time window. `traceActionDetail` returns one action's arguments, result, error with a failed assertion's expected and actual, and the test source around its call site, cut to fit a character budget. `traceTranscript` pages the zip's `transcript.md`. A poll that a passing wait retried past reads as `retried`, not failed, by the same rule the trace player uses. Times are milliseconds from the trace's start, and long values are cut, saying how long they were. `pageOf` now counts a page's wrapper and separators against its budget and takes a `scope`, so a cursor is refused by any listing other than the one that returned it.
